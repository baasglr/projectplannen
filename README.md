| [Crowdfunding](crowdfunding/README.md) | GLR Fotografie | Een website waar fotografiestudenten donateurs zoeken |

## Zo gebruik je een plan

1. Kopieer de map van jouw project naar je eigen repository.
2. Het plan heet `README.md`, dus GitHub laat het meteen op je repo-pagina zien.
3. Gebruik het plan als basis. Maak GitHub issues voor je planning en vul het hoofdstuk Testen aan met je eigen testresultaten.
